# CUDA 基础

## Kernel

kernel 是在 GPU 上执行、可由 host 端启动的函数。kernel 使用 `__global__` 修饰。

```cuda
__global__ void vec_add(const float* a, const float* b, float* c, int n) {
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (idx < n) {
        c[idx] = a[idx] + b[idx];
    }
}
```

函数限定符：

| 限定符 | 调用位置 | 执行位置 | 说明 |
| --- | --- | --- | --- |
| `__global__` | host，可被 device 启动的 dynamic parallelism 场景除外 | device | kernel 函数，使用 `<<<...>>>` 启动 |
| `__device__` | device | device | device 辅助函数 |
| `__host__` | host | host | host 函数；未显式标注时默认是 `__host__` |
| `__host__ __device__` | host 和 device | host 和 device | 编译生成 host/device 两个版本 |

## Kernel Launch

kernel launch 使用 `<<<grid, block, shared_mem, stream>>>` 指定执行配置。

```cuda
dim3 block(256);
dim3 grid((n + block.x - 1) / block.x);

vec_add<<<grid, block>>>(d_a, d_b, d_c, n);
```

完整形式：

```cuda
vec_add<<<grid, block, shared_mem_bytes, stream>>>(d_a, d_b, d_c, n);
```

参数含义：

| 参数 | 类型 | 作用 |
| --- | --- | --- |
| `grid` | `dim3` | grid 中 block 的数量 |
| `block` | `dim3` | 每个 block 中 thread 的数量 |
| `shared_mem_bytes` | `size_t` | 动态 shared memory 字节数 |
| `stream` | `cudaStream_t` | kernel 所属 stream |

只提供两个参数时，`shared_mem_bytes` 默认为 `0`，`stream` 默认为 default stream。

## 线程索引

一维 kernel 常用全局线程索引：

```cuda
int idx = blockIdx.x * blockDim.x + threadIdx.x;
```

内置变量：

| 变量 | 含义 |
| --- | --- |
| `threadIdx` | 当前线程在 block 内的坐标 |
| `blockIdx` | 当前 block 在 grid 内的坐标 |
| `blockDim` | 每个 block 的维度 |
| `gridDim` | grid 的维度 |

二维索引示例：

```cuda
int col = blockIdx.x * blockDim.x + threadIdx.x;
int row = blockIdx.y * blockDim.y + threadIdx.y;
int idx = row * width + col;
```

## Warp 和 Block

warp 是 GPU 调度和执行的基本线程组，通常包含 32 个线程。

block 是程序员指定的线程组织单位。一个 block 内的线程可以：

- 使用 shared memory 交换数据。
- 使用 `__syncthreads()` 做 block 内同步。

不同 block 之间没有直接同步机制。需要跨 block 同步时，通常拆成多个 kernel launch，或使用 cooperative groups 的特定启动方式。

## 内存管理 API

常见 API：

| API | 作用 |
| --- | --- |
| `cudaMalloc` | 在 device memory 中分配内存 |
| `cudaFree` | 释放 device memory |
| `cudaMemcpy` | CPU 和 GPU 之间同步拷贝数据 |
| `cudaMemset` | 设置 device memory 内容 |
| `cudaMemcpyAsync` | 异步拷贝，通常配合 stream 使用 |
| `cudaMallocHost` / `cudaFreeHost` | 分配/释放 pinned host memory |
| `cudaMallocManaged` | 分配 unified memory |
| `cudaMemPrefetchAsync` | 提示 unified memory 提前迁移到指定 device |
| `cudaMallocPitch` | 分配二维数组常用的对齐 device memory |
| `cudaMallocAsync` / `cudaFreeAsync` | stream-ordered 异步分配/释放 |

## 错误检查

CUDA runtime API 返回 `cudaError_t`。kernel launch 错误需要在 launch 后显式检查。

```cuda
#define CHECK_CUDA(call)                                                \
    do {                                                                \
        cudaError_t err = (call);                                       \
        if (err != cudaSuccess) {                                       \
            fprintf(stderr, "CUDA error %s:%d: %s\n",                  \
                    __FILE__, __LINE__, cudaGetErrorString(err));       \
            std::abort();                                               \
        }                                                               \
    } while (0)
```

kernel launch 后常用检查：

```cuda
vec_add<<<grid, block>>>(d_a, d_b, d_c, n);
CHECK_CUDA(cudaGetLastError());
CHECK_CUDA(cudaDeviceSynchronize());
```

`cudaGetLastError()` 检查 launch 配置等同步前即可发现的错误。`cudaDeviceSynchronize()` 等待 kernel 执行完成，并返回执行期间发生的错误。

## 同步

kernel launch 默认是异步的。host 线程启动 kernel 后通常会继续执行。

显式同步：

```cuda
cudaDeviceSynchronize();
```

常见同步来源：

| 操作 | 同步范围 |
| --- | --- |
| `cudaDeviceSynchronize()` | 当前 device 上此前提交的工作 |
| `cudaStreamSynchronize(stream)` | 指定 stream |
| 同步版 `cudaMemcpy` | 与相关拷贝方向和默认 stream 语义有关 |
| `cudaEventSynchronize(event)` | 等待指定 event 完成 |

## 完整示例

```cuda
#include <cuda_runtime.h>

#include <cstdio>
#include <cstdlib>
#include <iostream>
#include <vector>

#define CHECK_CUDA(call)                                                \
    do {                                                                \
        cudaError_t err = (call);                                       \
        if (err != cudaSuccess) {                                       \
            fprintf(stderr, "CUDA error %s:%d: %s\n",                  \
                    __FILE__, __LINE__, cudaGetErrorString(err));       \
            std::abort();                                               \
        }                                                               \
    } while (0)

__global__ void vec_add(const float* a, const float* b, float* c, int n) {
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (idx < n) {
        c[idx] = a[idx] + b[idx];
    }
}

int main() {
    int n = 1 << 20;
    size_t bytes = static_cast<size_t>(n) * sizeof(float);

    std::vector<float> h_a(n, 1.0f);
    std::vector<float> h_b(n, 2.0f);
    std::vector<float> h_c(n, 0.0f);

    float* d_a = nullptr;
    float* d_b = nullptr;
    float* d_c = nullptr;

    CHECK_CUDA(cudaMalloc(&d_a, bytes));
    CHECK_CUDA(cudaMalloc(&d_b, bytes));
    CHECK_CUDA(cudaMalloc(&d_c, bytes));

    CHECK_CUDA(cudaMemcpy(d_a, h_a.data(), bytes, cudaMemcpyHostToDevice));
    CHECK_CUDA(cudaMemcpy(d_b, h_b.data(), bytes, cudaMemcpyHostToDevice));

    dim3 block(256);
    dim3 grid((n + block.x - 1) / block.x);

    vec_add<<<grid, block>>>(d_a, d_b, d_c, n);
    CHECK_CUDA(cudaGetLastError());
    CHECK_CUDA(cudaDeviceSynchronize());

    CHECK_CUDA(cudaMemcpy(h_c.data(), d_c, bytes, cudaMemcpyDeviceToHost));

    std::cout << "h_c[0] = " << h_c[0] << std::endl;
    std::cout << "h_c[n-1] = " << h_c[n - 1] << std::endl;

    CHECK_CUDA(cudaFree(d_a));
    CHECK_CUDA(cudaFree(d_b));
    CHECK_CUDA(cudaFree(d_c));

    return 0;
}
```
