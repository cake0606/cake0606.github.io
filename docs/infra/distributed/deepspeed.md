# DeepSpeed
## 大模型训练显存占用
模型训练过程中的显存占用分为四个部分：
- 模型参数占用
- 梯度占用
- 优化器占用
- 激活值占用
在进行混合精度训练时， 一般模型在训练时使用fp16来存储模型权重， 但是在backward时会使用fp32的模型权重和优化器。
## ZeRO R1
在`ZeRO R1`中采用的方法是切分优化器状态。将优化器切分到多个GPU上， 每个GPU保存完整的模型权重， 进行完整的forward和backward， 只更新其负责部分的优化器状态。每轮训练完成后， 通过reduce-scatter将梯度同步到负责的机器上， 

## ZeRO R2
假设每台设备只能训练部分参数，就不需要保存其他参数的梯度。
在`ZeRO R2`中，将优化器状态和梯度切分到多个GPU上，进行backward更新时， 每经过一层参数， 就通过reduce-scatter将梯度更新到一个节点上， 计算出下一个梯度时删除前一个梯度。

## ZeRO R3
将优化器参数、梯度、模型权重都切分到多个GPU上， 显存占用的减少与GPU数量成正比, 但是每一轮都会进行broadcast，增加了很多通信量。
