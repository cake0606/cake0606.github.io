## 文件复制、移动、删除
首先通过touch创建文件
```
test/linux/d1
> touch a.md

test/linux/d1
> ls
a.md
```
### cp： 拷贝文件和目录
对文件进行拷贝
```
test/linux/d1
> cp a.md a_copied.md # 拷贝并创建一个文件

test/linux/d1
> ls
a.md  a_copied.md

test/linux/d1
> cp a.md ../d2

test/linux/d1
> ls ../d2
a.md

test/linux/d1
> cp a.md ../d2/a_copied.md # 将文件拷贝到对应目录下，并且命名

test/linux/d1
> ls ../d2
a.md  a_copied.md
```
对目录进行拷贝， -r 递归复制， -a 归档复制， -v 可视化
```
project/test/linux
> cp -r d1 d2 # 递归复制目录及目录内内容

project/test/linux
> cp -a d1 d3 # achrived, 尽可能保留原有属性
```
```
project/test/linux
> cp -av d1 d4
'd1' → 'd4'
'd1/a.md' → 'd4/a.md'
'd1/a_copied.md' → 'd4/a_copied.md'
```
### mv: 用来移动或重命名文件
```

test/linux/proj
> mv old.md new.md # 重命名

test/linux/proj
> ls
new.md

test/linux/proj
> mv new.md ../backup # 移动文件到目标目录

test/linux/proj
> cd ..

project/test/linux
> mv proj backup/ # 移动整个文件夹

project/test/linux
> ls backup
new.md  proj
```
#### rm: 删除文件和目录
```

test/linux/backup
> rm new.md # 删除文件

test/linux/backup
> rm proj/ # 报错
rm: cannot remove 'proj/': Is a directory

test/linux/backup
x rm -r proj/ # 目录需要递归删除
```
## 用户权限
对于普通文件
- r: 读取文件内容
- w：修改文件内容
- x： 将文件作为程序执行
对于目录:
- r: 查看目录中的文件名
- w： 在目录中创建、删除、修改文件
- x：进入和访问目录中的项目
### chmod: 修改权限
```
chmod u+x file.md # 给用户增加执行权限
chmod g+w file.md # 给组增加写权限
chmod o+r file.md # 取消其他用户读权限
```
其中， 对象缩写为:
```
u：所有者
g：所属组
o：其他用户
a：所有人
```
操作符为:
```
+：增加权限
-：移除权限
=：设置为指定权限
```
