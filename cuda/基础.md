# 内核
在GPU上执行且可以被主机调用的函数。
## 内核代码
内核代码使用`__global__`来指定，告诉编译器： 这个函数是一个gpu kernel， 需要被编译成GPU代码， 并且可以通过`<<<grid, block>>>`这种kernel launch 语法启动。
> 对比__global__,__device__, __host__
    `__global__`通常由cpu用<<<>>>启动， 在gpu执行。
    `__device__`由GPU函数调用， 在GPU执行。
    `__host__`由CPU调用， 在CPU执行。
### <<<>>>表示法
用<<<>>>封装启动的配置参数
```cu 
__global__ void vecadd(float *a, float * b) {

}

int main() {
    vecadd<<<1, 256>>>(a, b);
}
```
前两个参数分别是线程网格维度和线程块维度。

代码示例：
```cu

  int main() {
      int n = 1 << 20;
      size_t bytes = n * sizeof(float);

      std::vector<float> h_a(n, 1.0f);
      std::vector<float> h_b(n, 2.0f);
      std::vector<float> h_c(n, 0.0f);

      float* d_a = nullptr;
      float* d_b = nullptr;
      float* d_c = nullptr;

      // 1. 在 GPU 显存中分配空间
      CHECK_CUDA(cudaMalloc(&d_a, bytes));
      CHECK_CUDA(cudaMalloc(&d_b, bytes));
      CHECK_CUDA(cudaMalloc(&d_c, bytes));

      // 2. 把 CPU 数据拷贝到 GPU
      CHECK_CUDA(cudaMemcpy(d_a, h_a.data(), bytes, cudaMemcpyHostToDevice));
      CHECK_CUDA(cudaMemcpy(d_b, h_b.data(), bytes, cudaMemcpyHostToDevice));

      // 3. 启动 kernel，在 GPU 上计算
      int threads = 256;
      int blocks = (n + threads - 1) / threads;
      vecAdd<<<blocks, threads>>>(d_a, d_b, d_c, n);

      CHECK_CUDA(cudaGetLastError());
      CHECK_CUDA(cudaDeviceSynchronize());

      // 4. 把结果从 GPU 拷贝回 CPU
      CHECK_CUDA(cudaMemcpy(h_c.data(), d_c, bytes, cudaMemcpyDeviceToHost));

      std::cout << "h_c[0] = " << h_c[0] << std::endl;
      std::cout << "h_c[n-1] = " << h_c[n - 1] << std::endl;

      // 5. 释放 GPU 显存
      CHECK_CUDA(cudaFree(d_a));
      CHECK_CUDA(cudaFree(d_b));
      CHECK_CUDA(cudaFree(d_c));

      return 0;
  }
```

### CPU和GPU同步
kernel launch默认是异步的，当CPU需要GPU结果时， 必须显示同步。
```
addkernel<<<1, N>>>(d_c, d_a, d_b);

cudaDeviceSynchronize();

cudaMemcpy(h_c, d_c, N * sizeof(int), cudaMemcpyDeviceToHost);
```
